# Durham Web Design — Landing Page

> Ultra-fast, modern web design and managed Canadian cloud hosting engineered for businesses across Durham Region, Ontario.

---

## 🍁 Overview

**Durham Web Design** is a high-converting digital agency landing page tailored for small and medium businesses in Durham Region (Oshawa, Whitby, Ajax, Pickering, Bowmanville, Courtice, and Brooklin).

Built on top of **Epic Expressions** cloud infrastructure, this project delivers sub-second page performance, zero dependency overhead, and transparent Canadian Dollar (CAD) pricing.

---

## ⚡ Tech Stack & Architecture

- **Format:** Zero-dependency, standalone HTML5 / CSS3 / JavaScript
- **Design System:** Dark tech theme (deep slate & obsidian surfaces with electric blue and emerald accents)
- **Typography:** `Plus Jakarta Sans` & `JetBrains Mono`
- **Effects:** High-contrast responsive layout, glassmorphism (`backdrop-filter`), and CSS micro-interactions
- **Form Handling:** Client-side validation and interactive state handling for lead capture

7. **Footer:** Branded credit for *Epic Expressions cloud infrastructure*.

## 🌐 Deployment Instructions

### 1. Local Testing
Double-click `index.html` or run in PowerShell:
```powershell
Start-Process "index.html"
```

### 2. Linux Cloud VPS (Nginx / Apache)
Upload via SCP:
```bash
scp index.html user@your-server-ip:/var/www/durhamwebdesign/
```

### 3. Edge CDN (Cloudflare Pages / Vercel / GitHub Pages)
Connect this repository directly to Cloudflare Pages or Vercel:
- **Build command:** *(none)*
- **Output directory:** `.` (root)
